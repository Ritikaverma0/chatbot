# 🤖 Simple ChatBot API with Flask

This project is a basic chatbot API built using **Python** and **Flask**. It reads questions and answers from a `dataset.json` file and responds to user input through a simple HTTP POST request.

---

## 🚀 Features

- Lightweight chatbot using predefined question-answer pairs.
- Built with Flask for easy web integration.
- Supports both local console chat and web-based API chat.
- Easily extendable dataset (`dataset.json`).

---


## 📦 Requirements

- Python 3.x
- Flask
